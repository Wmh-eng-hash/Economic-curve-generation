算法说明

1. 核：线性/对数线性供需　D: q = A − |Ed|·p，S: q = B + Es·(p − τ)，均衡 η = (A−B+Es·τ)/(Es+|Ed|)。需求曲线右移 → P↑ Q↑；供给曲线右移 → P↓ Q↑；成本↑ → 供给左移 → P↑ Q↓。价格因素只引起沿需求曲线移动，非价格因素引起曲线整体位移。
2. 黄金特例　没有生产成本意义上的供给弹性，库存即流量：价格 = f(实际利率 i−π, 美元指数, 风险溢价/地缘, 央行购金, 投机因子)，并用历史年均价做弱均值回归（2026 YTD 4542.81 为实时锚，HistorySaid 4886.36 为预测锚）。
3. 原油特例　短期供给近零弹性（投资周期 3–5 年）；把 OPEC 闲置产能作为供给弹性的“调节阀”：闲置产能高 → 同样冲击价格变化小；闲置产能低 + 断供 → 价格尖峰（2020 负油价 / 2022 冲突两种极端）。
4. 天然气特例　难储运 → 库存就是供给；需求高度季节性与天气驱动，冬季低库存触发非线性尖峰，淡季高库存触发塌陷。
5. 日用品　标价（厂商建议零售价）是心理锚，实付价 = 标价 ×(1−折扣率)；折扣率随需求冲击与渠道议价移动，属“价格歧视 + 促销”下的高弹性市场。
6. 实时　dP/P = κ(lnTarget − lnP)dt + σdW，观测价每 tick 更新一次并与先验做卡尔曼式加权；事件冲击按半衰期衰减（商品 75h、日用品 300h），预期/传闻类事件权重减半。
7. 通胀判定　由每日录入的「名义利率 − 核心 CPI」得到实际利率，判定通胀/通缩/低通胀，并计算输入型通胀与“极端情景强度”，用于黄金机会成本与极端模式的特例算法。
数据口径：黄金 MoneyMetals / HistorySaid；布伦特与 Henry Hub：FRED / HistorySaid；2026 年商品为 YTD 均价或预估；日用品标价/实付为 2026 年实测。商品事件为按公开年度走势整理的示例，请以你导入的真实新闻库为准。
