# 供需·价格 实时引擎 (SPVP)

> 一个单文件、零依赖的浏览器端「需求-供给 / 价格-数量」实时推演引擎。
> 把教科书里的供需曲线，变成可以手绘、可以用新闻事件驱动、可以实时跳动的价格。

---

## 这是什么

`1.0供需价格引擎.html` 是一个**完整的单文件 Web 应用**（HTML + CSS + 原生 JS，无构建、无后端、无第三方依赖）。它把经济学中最基础的「供需决定价格」模型做成了三层可交互的推演工具：

1. **自动模式** —— 内置黄金、布伦特原油、Henry Hub 天然气、日用品实测、自定义商品五类标的，价格按 ODE 实时跳动，并持续向「模型出清目标」回归。
2. **手绘模式** —— 逐项勾选「价格因素 / 非价格因素」，实时画出需求曲线与供给曲线的位移，区分「沿曲线移动」与「曲线整体位移」，并结算新的均衡价与均衡量。
3. **新闻库 / TXT 解码** —— 拖入 `.txt` 文本（支持 UTF-8 / GBK / UTF-16 / Big5 自动识别，CSV / TSV / 竖线 / 空格表格 / JSON / 自由新闻体多格式），解析成带方向的冲击事件，立刻进入算法。

---
